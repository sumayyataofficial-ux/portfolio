# Sumayya Ameer — Portfolio

A minimal, animated software-developer portfolio (HTML + CSS + JS, no build step).

## Files
```
index.html                    page content
style.css                     design, dark/light themes, mobile layout
script.js                     theme toggle, typing effect, scroll animations, mobile menu
assets/avatar.png             illustrated profile photo
assets/Sumayya_Ameer_CV.pdf   CV used by the "Download CV" buttons
```

## Edit later
- Text: edit `index.html`.
- Colours: change the variables at the top of `style.css` (`--accent`, `--accent-2`).
- New CV: replace `assets/Sumayya_Ameer_CV.pdf` with a file of the same name.
- Typing roles: edit the `roles` list in `script.js`.

## Deploy
Push to GitHub → import the repository in Vercel (Framework Preset: Other) → Deploy.
Every later push to `main` redeploys automatically.
